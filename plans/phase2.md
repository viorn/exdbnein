# Этап 2 — Профили и наборы пакетов

Статус: ⬜ не начат.
Источник анализа: [`plans/plan-analysis.md`](plan-analysis.md), раздел «Этап 2».

## Цель

Предзаготовленные наборы софта и действий в YAML, с наследованием через `extends`.
Профиль выбирается в визарде и применяется в фазе B (этап 7).

## Формат профиля

```yaml
# profiles/desktop-gnome.yaml
name: desktop-gnome
description: GNOME на базе desktop
extends: desktop            # строка или список; можно несколько родителей

packages:                   # пакеты apt
  - gnome
  - gnome-tweaks

services:                   # systemd-юниты для enable
  - gdm3

commands:                   # команды в chroot, по порядку (произвольный shell)
  - cmd: systemctl set-default graphical.target
    description: Загрузка в графический режим
    optional: true          # не прерывать установку при ошибке

files:                      # файлы, создаваемые в целевой системе
  - path: /etc/skel/.config/example.conf
    content: |
      key=value
    mode: "0644"
```

## Правила слияния при наследовании

- `packages`, `services`, `commands`, `files` — конкатенация родителей (в порядке `extends`), затем свои.
- `packages`/`services` дедуплицируются (union); `commands`/`files` сохраняют порядок.
- Скалярные поля (`name`, `description`) — переопределяются потомком.
- Циклы в `extends` — ошибка; глубина и число профилей ограничены.
- Порядок применения: топологическая сортировка по `extends`.

## Принятые решения

- **Конфликт файлов** (два профиля пишут разные содержимое по одному пути) — ошибка валидации,
  а не молчаливый «последний побеждает».
- **`commands` — доверенный источник.** Встроенные профили считаются доверенными; при использовании
  внешних `--profiles-dir` перед применением показать список команд и предупредить о недоверенном источнике.
- **Развёрнутый профиль** (flat list после резолва) сохранять в конфиг/лог — применение на этапе 7
  детерминировано и повторяемо.

- `bun run start -- --profiles-dir <dir>` показывает профили из обоих источников, выбор работает.
- Наследование: цепочки, дубли, циклы покрыты тестами; конфликт файлов даёт ошибку валидации.
- Итоговый набор пакетов/команд/файлов можно просмотреть до подтверждения установки.
- Встроенные профили `base`, `server`, `desktop`, `dev` валидны.
- `bun run check` зелёный.
