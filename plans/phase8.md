# Этап 8 — Сборка LiveCD

Статус: ⬜ не начат.
Источник анализа: [`plans/plan-analysis.md`](plan-analysis.md), раздел «Этап 8».

## Цель

Собрать загрузочный ISO с установщиком: live-система Debian, скомпилированный бинарь exdbnein,
инструменты разметки, автозапуск установщика на tty1 и маркер LiveCD.

## Задачи

- [ ] `livecd/build.sh`: сборка live-системы (debootstrap) + установка установщика
- [ ] Упаковка установщика: `bun build --compile` (без зависимости от bun в Live)
- [ ] Доставка YAML-профилей: инлайн в TS-модули или рядом с бинарём в ISO (P8.1)
- [ ] squashfs + initramfs + загрузчик (GRUB, гибридный ISO BIOS+UEFI)
- [ ] Автозапуск установщика на tty1 (systemd-юнит), live-пользователь, сеть из коробки
- [ ] Маркер LiveCD `/etc/exdbnein-live` (P8.2)
- [ ] Сборка ISO через `xorriso`/`grub-mkrescue`

## Принятые решения

- **Автозапуск:** systemd-юнит на tty1 (getty override), а не кастомный init — для MVP проще
  и надёжнее (P8.3).
- **Маркер LiveCD:** `/etc/exdbnein-live` создаётся в live-системе на этапе сборки;
  его проверяет этап 3 ([`plans/phase3.md`](phase3.md)).

## Риски

- P8.1 🟡 `bun build --compile` не упаковывает YAML-ассеты — профили компилируются в TS-модули
  (инлайн) либо кладутся рядом с бинарём; формат влияет на этап 2.
- P8.2 🟡 Маркер LiveCD создаётся здесь — согласован с этапом 3.
- P8.3 🔵 Кастомный init — отказаться в пользу live-boot/systemd-юнита.

## Критерии готовности

- ISO грузится в QEMU (BIOS и UEFI), установщик стартует автоматически на tty1.
- `lsblk` показывает носитель LiveCD как съёмный; установщик исключает его из целевых дисков.
- Сборка воспроизводима с хоста без Live (список пакетов сборщика зафиксирован).
