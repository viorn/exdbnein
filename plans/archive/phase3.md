## Принятые решения

- Маркер LiveCD: файл `/etc/exdbnein-live`, создаётся сборкой ISO (этап 8).
- Dev-режим (`--force`) — единственный способ запустить установщик вне LiveCD.
  Проверка root обязательна всегда, `--force` не отменяет её.
- «Носитель LiveCD» определяется эвристикой по mountpoints: диск исключается из выбора,
  если у него (или дочерних разделов) есть монтирования `/`, `/run/live*`, `/cdrom`, `/media/*`.
  Это также защищает системный диск текущей ОС при dev-запусках.
- Проверка сети — мягкая: предупреждение на ревью, установку не блокирует.
