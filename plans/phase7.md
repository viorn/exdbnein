# Этап 7 — Пост-установка и завершение

Статус: ⬜ не начат.
Источник анализа: [`plans/plan-analysis.md`](plan-analysis.md), раздел «Этап 7».

## Цель

Фаза B: применить выбранные профили в установленную систему, выполнить хуки, очистить временные
файлы, размонтировать диск и предложить перезагрузку.

## Задачи

- [ ] Применение профилей: установка пакетов, включение сервисов, `commands`, `files`
- [ ] Чёткое разделение «пространств путей»: файлы пишутся с префиксом целевого корня
      (`/mnt/etc/...`), команды выполняются в chroot (P7.1)
- [ ] Хуки/скрипты пользователя после установки
- [ ] Очистка: `apt clean`, удаление временных файлов
- [ ] Размонтирование, `swapoff`, финальный экран, `reboot` (в `finally`-блоках, P7.3)
- [ ] Стратегия ошибок: понятный отчёт + повторный запуск поверх готовой разметки (P7.2)

## Принятые решения

- **Rollback не предусмотрен** (данные уже стёрты — нечего откатывать). Вместо него:
  лог шагов в `/var/log/exdbnein/install.log` (на LiveCD-носителе или в памяти) и идемпотентный
  повторный вход — установщик распознаёт уже размеченный диск и продолжает с места ошибки.
- `files` из профилей — это пути целевой системы; writer добавляет префикс корня монтирования.
  `commands` — выполняются через chroot и видят корень целевой системы напрямую. Это требование
  фиксируется в схеме профиля (см. [`plans/phase2.md`](phase2.md)).
- Размонтирование `/mnt` и `swapoff` выполняются всегда — даже при ошибке (finally).

## Риски

- P7.1 🔴 Два разных «пространства путей» (writer vs chroot runner) — задокументировать и разделить в коде.
- P7.2 🔴 Нет rollback — стратегия «отчёт + повторный запуск» выше.
- P7.3 🟡 Очистка при ошибке — finally вместо happy-path.

## Критерии готовности

- Профили применяются полностью: пакеты установлены, сервисы включены, файлы на месте,
  команды выполнились (optional-ошибки не прерывают установку).
- При любой ошибке фазы B остаётся читаемый лог и корректно размонтированный диск.
- После успеха — финальный экран и reboot по выбору.
- `bun run check` зелёный.
