# Этап 4 — Разметка диска

Статус: ⬜ не начат.
Источник анализа: [`plans/plan-analysis.md`](plan-analysis.md), раздел «Этап 4».

## Цель

Начало фазы B (применения): подготовить целевой диск — таблица разделов, файловые системы,
subvolumes btrfs, монтирование в `/mnt`. Это **первая необратимая точка** установки:
данные на выбранном диске будут стёрты.

## Задачи

- [ ] Выбор диска из списка этапа 3 (не носитель LiveCD)
- [ ] Схемы: авто (wipe), ручная, «оставить существующие разделы» (keep — упрощённо, для MVP)
- [ ] UEFI → GPT + ESP (fat32) + `/` (+ swap); BIOS → MBR + `/` (+ swap) (P4.1)
- [ ] ФС: `btrfs` (приоритет) и `ext4`
- [ ] btrfs subvolumes `@`, `@home`, `@snapshots` и монтирование с `compress=zstd,noatime`
- [ ] Генерация имён разделов с `pN`-суффиксом для NVMe/MMC (P4.2)
- [ ] Разметка через `parted`/`sgdisk`, форматирование (`mkfs.btrfs`, `mkfs.ext4`, `mkfs.fat`, `mkswap`)
- [ ] Монтирование в `/mnt` и `/mnt/boot/efi` (UEFI)
- [ ] Экран подтверждения с точным списком команд (dry-run)
- [ ] Защита от повторного wipe при повторном входе (P4.3)

## Принятые решения

- **BIOS → MBR, UEFI → GPT** (зафиксировано в [`plans/plan.md`](plan.md)).
- Модуль `src/system/disks.ts` — единственное место генерации имён разделов и таблиц разметки;
  генерируемые команды показываются в dry-run и исполняются напрямую (без shell).
- После успешной разметки шаг помечается выполненным; повторный запуск установщика поверх готовой
  разметки должен распознавать её (идемпотентный вход, сценарий S4 из анализа).

## Риски

- P4.1 🔴 BIOS + GPT требует раздела `bios_grub` — решено: BIOS использует MBR.
- P4.2 🟡 Суффикс `pN` у NVMe/MMC — покрыто тестами в `system/disks.ts`.
- P4.3 🔴 Повторный wipe после возврата «назад» — back разрешён только в фазе A (см. phase1 P1.2);
  в фазе B линейный раннер без возвратов.
- P4.4 🔵 Dry-run команды должны быть точными — использовать UUID-подписи (см. phase5), итоговая
  таблица разделов с размерами в GiB.

## Критерии готовности

- Dry-run перед разметкой показывает полный и корректный список команд; до подтверждения
  ничего на диске не меняется.
- UEFI (GPT+ESP) и BIOS (MBR) раскладки собираются в QEMU-дисках (этап 9).
- Имена разделов корректны для `sda`/`nvme0n1`/`mmcblk0` — тесты зелёные.
- Повторный запуск после незавершённой установки распознаёт уже размеченный диск.
- `bun run check` зелёный.
